# GCC BANK - Banking System in C++

My Project
I created this project for my Introduction to Programming assignment at Gauteng City College.

I made a command line banking system in C++. It lets a user deposit money, withdraw money, send cash to another person, and check their balance.

## What My Program Can Do
When I run the program, it shows me a menu:
1. Deposit - I can add money to my account. The amount must be more than 0.
2. Withdraw - I can take money out. I cannot withdraw more than my balance.
3. Send Cash - I can send money to another account. My program checks if the account exists and if I have enough balance.
4. Check Balance - I can see how much money I have left.
5. Exit - I can close the program.
